# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 邻串阴影剔除

遮挡会让单点填充因子飞掉。顶栏「阴影剔除」专页提供可关的剔除开关，并对照跳幅门槛与邻串窗长：

- **开启时**：交单口（`POST /api/logs`）把本串 FF 与同阵列**邻串**近窗 FF 中位数对照，跳幅严格超过门槛则整笔退回（HTTP 422）——提交的灯不亮、单子不入队、不会被工人收走，只在「拦住履历」留底（含当时开关、门槛、窗长、邻串中位、邻串笔数快照）。
- **关闭后**：新单一律不再按阴影拦，同类飞点可正常进队出结论；旧拦住履历仍可翻。
- **近时重复**：贴门槛几乎同时到的两笔同串近似单（默认 5 秒内、FF 差 ≤0.005），无论剔除开关是开是关都最多收一笔，后到者 409 并留履历，避免重复交单混进队列。
- **权限**：旁观账号只能看开关对照参数、翻拦住履历；扳开关、改门槛窗长、交单均 403。
- 编号需形如 `阵列A-串03` 才参与邻串对照（阵列=末段 `-串数字` 之前部分，邻串=同阵列不同串号）；无法解析的编号不收阴影规则约束。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/shadow/settings` | 登录 | 看开关/门槛/窗长 |
| PUT | `/api/shadow/settings` | writer | 改开关/门槛（0,1] /窗长（1–1440 分钟） |
| GET | `/api/shadow/rejections` | 登录 | 翻拦住履历（近 200 笔） |
| POST | `/api/logs` | writer | 交单；422=邻串阴影拦住，409=近时重复 |
