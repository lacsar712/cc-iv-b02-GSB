# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 邻串阴影剔除

遮挡会让单点填充因子飞掉。顶栏「邻串阴影剔除」专页提供可关的阴影闸门（默认关）：

- 闸门打开时，交单口先把本笔与同阵列相邻组串（编号 ±1）的近窗已入队扫描对照；本串 FF 相对邻串窗口中位跳变超过阈值（默认 0.20）→ 整笔记为 `blocked` 进**拦住履历**，不进工人队列、不发 NOTIFY。
- 同一组串在对照窗长内（默认 90 秒，可调 5–600）已有一笔入队 → 后到的一笔拦住，贴门槛几乎同时到的两笔最多留一笔（交单口对同组串编号加事务咨询锁防并发双笔）。
- 邻串基线不足两串时不猜测，放行；每个邻串只取窗内最新一笔参与中位。
- 闸门关闭后新单一律不再拦（同类飞点也能进队），但**旧拦住履历仍可翻**。
- 专页含开关、窗长/阈值参数、开关对照试算窗（`POST /api/shadow/preview`，只模拟不写库）、拦住履历，并展示窗长等参数的最近改动人与时间。
- 旁观账号 watcher 只能翻拦住履历与看设置，扳开关、改参数返回 403。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领（只认领 `pending`）
- 前端：Vue 3、Vite、nginx 反代 `/api`
